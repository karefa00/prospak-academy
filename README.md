# Prospak Academy — Student Portal & Grade Management System

Project approval: Phase 0 complete (3 November 2026). A new Git repository has been authorised. The approved roadmap has 14 phases; each phase requires manual testing and explicit approval before advancing.

Technology: PHP 8.x, MySQL 8.x, PDO, Apache on Ubuntu, Hope UI v5.0.0, Bootstrap 5 and vanilla JavaScript.

Administrator-created student and lecturer accounts. No public student or lecturer registration. Grade and academic policies must be approved before implementation.

Branch `feature/phase-1-authentication` adds the first application functionality; the `main` branch is the stable planning baseline.
